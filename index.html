用法

1. 时间轴是当天 24 小时的整点胶囊（3 行 × 8 格，0:00–23:00），块内按真实占比显示颜色，同一小时填多段，各段按时间位置独立成块；当前时刻的胶囊用深色外框标出
2. 点任意胶囊：弹窗里能看本小时已填的段，并手动填开始/结束的「几点几分」（默认整点，分钟你自己改）。分类一键选
3. 一个胶囊可填多段（如 14:00–14:20 工作、14:20–14:30 学习），各段按自己的时间位置各占一截
4. 吃饭 / 日常选「吃饭 / 日常」分类——看得见，但不算进 学习/工作/娱乐/运动/社交 五类占比
5. 饮食 / 运动打卡：点卡片里的项打勾，自动在对应时间生成记录段；打满即亮「今日自律」
6. 昨天默认能补；手机上：浏览器打开 → 分享 → 添加到主屏幕
7. 云同步：设置里填一次 GitHub 令牌，点「☁️ 同步到云端」上传；换设备填同一个令牌、点一次同步即可拉取共用
